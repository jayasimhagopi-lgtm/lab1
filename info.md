# 🎓 Student Registration Form

A clean and responsive Student Registration Form designed using **HTML and CSS**. The form provides a simple and user-friendly interface for collecting student information such as personal details, contact information, gender, date of birth, course, and address.

## ✨ Features

- Student name input
- Email address input
- Phone number input
- Gender selection
- Date of birth field
- Course selection
- Address field
- Register button
- Clear button
- Clean and responsive design

## 💻 Technologies Used

- HTML5
- CSS3

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open the `index.html` file in a web browser.
